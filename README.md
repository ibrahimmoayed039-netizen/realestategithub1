# إدارة العقارات والعملاء (Electron)

تشغيل محلي:
    npm install
    npm start

بناء ملف التثبيت:
    npm run dist

على GitHub: ارفع كل الملفات (مع مجلد .github) إلى الفرع main،
ثم Actions > Build > Artifacts لتحميل ملف .exe / .dmg / .AppImage.

ملاحظة عن الأداء: تُحفظ صور كل عقار في ملف مستقل داخل مجلد photos (بجانب data.json)،
وتُعرض القائمة على دفعات (40 عقاراً في كل مرة) بصور مصغّرة، والنسخ الاحتياطي الكامل
يُنشأ مرة كل بضع دقائق وعند إغلاق البرنامج بدل كل عملية حفظ.
البيانات القديمة تُرحَّل تلقائياً عند أول تشغيل، ويُحفظ الملف القديم باسم data.pre-split.json.

## التفعيل (الترخيص)
- بدون تفعيل: فترة تجريبية 3 أيام وبحد أقصى 5 عقارات، وبعدها يُقفل البرنامج إلى أن يُفعَّل.
- من تبويب «التفعيل» ينسخ العميل «رقم الجهاز» ويرسله لك، فتصدر له مفتاحاً من ملف «صفحة التفعيلات» (activation-admin.html) وتعيده له.
- المفتاح مرتبط برقم الجهاز، ويمكن أن يكون دائماً أو محدد المدة.
- البرنامج يحمل المفتاح العام فقط داخل license.js (PUBLIC_KEY_JWK). المفتاح الخاص موجود في activation-admin.html
  ولا يجوز رفع هذا الملف إلى GitHub (مضاف إلى .gitignore).
- لتغيير الحدود التجريبية عدّل TRIAL_DAYS و TRIAL_MAX_RECORDS في أعلى license.js.
